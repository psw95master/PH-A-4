## 3. 확정 사항

### 3-1. 원가 구조 — 빠져 있던 3가지

노션 마진율이 35.9% 로 나온 이유는 대행구매 원가 셋이 빠져 있었기 때문이다.

1. **고객이 낸 배송비는 마진이 아니다** — 국내 택배사로 나가는 통과금액이라 원가에서도 빼야 한다
2. **국제 배송비 누락** — 노션의 ¥78 은 중국 내 배송까지였다. 국경 통과 구간이 통째로 빠져 있었다
3. **결제·판매 수수료 누락** — 결제액의 3~6.6%

`HG 건담 슈바르제테` 실측 (260827 타오바오 주문서를 한국 주소로 실제 조회):

```
고객 결제      25,000원   (판매가 22,000 + 배송비 3,000)
해외 원가     −19,860원   (¥96.5 = 商品总价 ¥66 + 运费 ¥9 + 跨境段运费 ¥21.5)
국내 출고     − 3,000원
수수료        − 1,658원
──────────────────────
남는 돈           482원   →  마진율 1.9%  →  판정: 기각
국내가 대비     96.9%     (국내 25,800원 vs 우리 25,000원)
```

### 3-2. 타오바오 국제 배송 요금 (260827 실측)

배송지를 한국으로 바꾸면 대륙 구간이 ¥12 → ¥9 로 줄어든다. 판매자가 보내는 곳이 최종 주소가 아니라 전운창고(转运仓)로 바뀌기 때문.

## 7. 미확정 — 파일럿에서 확인할 것

1. **마진율 커트라인** — `상품 서칭 시트` `C12` 에 임시 20%. 페리 확정 필요
2. **네이버 쇼핑 자동 수집** — 공식 API 가 있는 것으로 보이나 세리가 아직 검증 못 함. 안 되면 A1 도 페리 수동
3. **쿠팡 상품 페이지 접근** — 세리가 URL 로 개별 상품 페이지를 실제로 읽을 수 있는지 미검증. 안 되면 캡처 방식으로 복귀
